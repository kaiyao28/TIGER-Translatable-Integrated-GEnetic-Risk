# Contributing

TIGER is under active development in preparation for publication. Cloning,
testing, discussion and pull requests are welcome.

To keep the developing methodology, documented equations and software aligned,
every proposed change must be reviewed and approved by the TIGER maintainers
before it is merged. Please do not make unreviewed direct changes to the main
development branch.

Useful contributions include:

- reports and fixes for confirmed implementation or documentation errors;
- reproducibility and compatibility improvements;
- clearer documentation that does not alter the scientific method;
- focused tests of published equations; and
- carefully justified methodological proposals within the project scope.

For a possible methodological error, include a minimal reproducible example and
identify the relevant equation or draft-method section. Pull requests should
explain the scientific and software impact and include focused tests where
applicable.

The TIGER maintainers retain responsibility for scientific review, merging
and eventual releases. A pull request is a proposal and may be revised
or declined when it would conflict with the developing method or repository
scope. Intermediate edits do not require a separate change record; release
notes can summarize material changes when a public version is prepared.
